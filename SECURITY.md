# Güvenlik Politikası

OnlyWP ile ilgili bir güvenlik açığı tespit ettiyseniz açığın teknik ayrıntılarını herkese açık issue olarak paylaşmayın.

Hassas bilgiler, erişim anahtarları, oturum verileri, tokenlar veya kullanıcı verileri hiçbir şekilde public olarak paylaşılmamalıdır.

## Kapsam

Bu repository OnlyWP public dokümantasyonunu içerir. OnlyWP ana kaynak kodu private olarak tutulmaktadır.
