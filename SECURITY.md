# Güvenlik Politikası

OnlyFast ile ilgili bir güvenlik açığı tespit ettiyseniz açığın teknik ayrıntılarını herkese açık issue olarak paylaşmayın.

Hassas bilgiler, erişim anahtarları, oturum verileri, tokenlar veya kullanıcı verileri hiçbir şekilde public olarak paylaşılmamalıdır.

## Kapsam

Bu repository OnlyFast public dokümantasyonunu içerir. OnlyFast ana kaynak kodu private olarak tutulmaktadır.
